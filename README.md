# サブスクリプション ダッシュボード

モバイルアプリのサブスクリプション契約状況を可視化するインタラクティブなダッシュボードです。

## 機能

### KPI表示
- **有効サブスク数** - 現在のアクティブ契約数
- **新規登録** - 選択期間内の新規契約数
- **解約** - 選択期間内の解約数
- **MRR** - 月間経常収益（Monthly Recurring Revenue）
- **トライアル転換率** - 無料トライアルから有料への転換率

### フィルター機能
すべての数値・グラフがフィルターに連動して更新されます。

| フィルター | 選択肢 |
|-----------|--------|
| 期間 | 7日 / 30日 / 90日 / 6ヶ月 / 1年 |
| プラットフォーム | すべて / iOS / Android |
| プラン | すべて / 月額 / 年額 |

### グラフ
1. **サブスクリプション推移** - 有効契約数の時系列推移
2. **MRR推移** - 月間収益の時系列推移
3. **新規 vs 解約** - 新規登録と解約の比較棒グラフ
4. **トライアル転換率推移** - 転換率の時系列推移

### 生データ表示機能
ヘッダーの「生データ表示」ボタンから、データの詳細を確認できます。

- **テーブル表示** - 日別データを表形式で閲覧
- **JSON表示** - 構造化データをJSON形式で閲覧（シンタックスハイライト付き）
- **データ範囲選択** - フィルター適用データ / 全データ（400日分）
- **エクスポート機能**
  - クリップボードにコピー
  - CSVダウンロード
  - JSONダウンロード

## ダミーデータの特徴

### ランダム性
- **ページ読み込みごとに異なるデータ** - シードが現在時刻に基づいて生成
- コンソールにシード値が表示されます（`🎲 Data seed: XXXXX`）

### リアルな変動パターン
- **週末効果** - 土日は新規登録が少なめ（ガウス分布でばらつきあり）
- **季節トレンド** - 年間を通じた波（正弦波ベース）
- **成長トレンド** - 緩やかな右肩上がり（ランダムな成長率）
- **マーケティングスパイク** - ランダムなタイミングで2〜3日間の急増
- **不調期間** - ランダムな5〜15日間の低迷期（技術障害や競合影響を想定）
- **日次ノイズ** - ガウス分布による自然なばらつき

### プラットフォーム・プラン別の傾向
- iOS > Android（ユーザー数）
- 月額 > 年額（契約数）
- 年額の方が解約率が低い
- 年額の方がトライアル転換率が高い

## 使い方

### ブラウザで直接開く
```bash
# macOS
open subscription-dashboard.html

# Windows
start subscription-dashboard.html

# Linux
xdg-open subscription-dashboard.html
```

### ローカルサーバーで起動
```bash
# Python 3
python -m http.server 8000

# Node.js (npx)
npx serve .

# PHP
php -S localhost:8000
```
その後 http://localhost:8000/subscription-dashboard.html にアクセス

## 技術スタック

- **HTML5 / CSS3** - モダンなUI（CSS Grid, Flexbox, CSS Variables）
- **JavaScript (ES6+)** - バニラJS、外部フレームワーク不要
- **Chart.js** - グラフ描画ライブラリ（CDN経由）

## カスタマイズ

### 価格設定の変更
`generateData` メソッド内の以下の変数を変更：
```javascript
const monthlyPrice = 980;   // 月額料金
const yearlyPrice = 9800;   // 年額料金
```

### 初期データ量の変更
`Dashboard` クラスのコンストラクタで日数を変更：
```javascript
this.rawData = this.generator.generateData(400);  // 400日分
```
